# پورتفولیوی صورتی نئونی

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## شخصی‌سازی قبل از انتشار
- در `index.html` عبارت `[نام شما]` را با نام خودتان جایگزین کنید.
- ایمیل `hello@example.com` و لینک‌های GitHub و LinkedIn را عوض کنید.
- تصویر نمونه‌ی ابتدای سایت را با آدرس عکس خودتان جایگزین کنید.
- پروژه‌ها، گواهی‌ها و درصد مهارت‌ها را مطابق اطلاعات واقعی خودتان اصلاح کنید.
- برای تغییر رنگ‌ها، متغیرهای ابتدای `style.css` را ویرایش کنید.

## انتشار روی GitHub Pages
1. در GitHub یک repository بسازید (مثلاً `my-portfolio`).
2. فایل‌های `index.html`، `style.css` و `script.js` را در شاخه `main` آپلود کنید.
3. به **Settings → Pages** بروید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
6. پس از چند دقیقه آدرس سایت در همان صفحه نمایش داده می‌شود؛ معمولاً به شکل `https://USERNAME.github.io/my-portfolio/` است.

اگر می‌خواهید آدرس اصلی `https://USERNAME.github.io/` باشد، نام repository باید دقیقاً `USERNAME.github.io` باشد.
