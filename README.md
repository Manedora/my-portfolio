# Pink Neon Portfolio

A responsive personal portfolio website with a dark navy background, neon-pink accents, glowing details, and subtle animations.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive styling, and animations
- `script.js` — mobile navigation, typing effect, and active navigation state
- `README.md` — project instructions

## Run locally
Open `index.html` in a browser. For a better development workflow, use the Live Server extension in Visual Studio Code.

## Customize before publishing
- In `index.html`, replace `[Your Name]` with your name.
- Replace `hello@example.com` and the sample GitHub/LinkedIn links with your own contact details.
- Replace the sample portrait with your own image.
- Update the sample projects, certificates, and skill percentages with accurate information.
- Edit the CSS variables at the top of `style.css` to change the theme colors.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `my-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root on the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. After GitHub finishes publishing, the site URL will appear on the Pages settings screen. It will usually look like `https://USERNAME.github.io/my-portfolio/`.

For a personal site at `https://USERNAME.github.io/`, name the repository exactly `USERNAME.github.io`.
