# Zahra — Anime Neon Portfolio

A responsive portfolio inspired by the provided anime screenshot: dark cinematic background, red neon glow, glassmorphism cards, projects, and contact links.

## Files
- `index.html` — content and page structure
- `style.css` — layout, effects, responsive styles
- `script.js` — small reveal animation
- `anime-samurai-bg.png` — anime background image

## Personalize
- The displayed name is already set to **Zahra**.
- There is no LinkedIn link.
- Replace `https://github.com/` with your own GitHub profile URL.
- Replace `zahra@example.com` with your real email address.
- Edit the project names and technologies to match your own work.

## Publish on GitHub Pages
Upload all five files to the root of your existing repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
